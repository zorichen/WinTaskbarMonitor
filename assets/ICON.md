# Application icon

Blue/cyan rounded tile with a white processor and a performance pulse. The icon is embedded in the Windows executable and used for the form and notification-area icon. The monitoring text layout is unchanged.

Generated with the built-in image_gen tool on 2026-09-09. Original image copied without modification to `icon-master.png`. `tools/package_icon.py` only converts format and resizes; it preserves alpha and does not redraw the artwork.

`taskbar-monitor.ico` includes 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel variants.

## Generation prompt

Use case: logo-brand. Asset type: actual production Windows application icon for a minimal CPU, memory and hardware-temperature taskbar monitor. Generate ONE original square icon, not a presentation sheet or mockup. A beautifully balanced Windows 11 Fluent-inspired blue-to-cyan rounded-square tile, straight front-on, containing one very simple bold white microchip outline with just two short pins per edge and a bold cyan/white angular performance pulse through its center. The chip and pulse form a single coherent unmistakable silhouette. Minimal refined geometry, thick clean strokes, restrained soft dimensionality in the tile only. Legible at 16px and 32px: avoid fine details, tiny gaps, multiple separate pictograms, text, letters, numbers, medical heart symbols, surrounding props and drop shadows outside the tile. Strong white-symbol contrast on rich royal blue, gentle turquoise accent, generous internal breathing space. Tile occupies approximately 90% of a square canvas. Genuine transparent alpha outside the rounded square; no checkerboard drawn into the pixels. 1024x1024 master asset. No watermark.
